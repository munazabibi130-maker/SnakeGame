# 🐍 Snake Game in C++

## 📌 Project Overview
This is a text-based Snake Game developed using C++. The game runs in the console and allows the player to control a snake, move around the playing area, and eat food to increase the score.

The project is designed to practice C++ programming fundamentals and game logic.

## ✨ Features
- Text-based console interface.
- Control the snake using keyboard keys.
- Eat food to increase the score.
- Score tracking during gameplay.
- Game-over condition when the snake hits an obstacle or itself, if implemented.

## 🛠️ Technologies Used
- **Programming Language:** C++
- **Interface:** Console / Text-Based
- **Concepts:** Loops, Conditional Statements, Functions, Variables, and Game Logic.

## 🎮 How to Play
1. Run the program.
2. Use the supported keyboard controls to move the snake.
3. Eat the food to increase your score.
4. Avoid collisions with walls or the snake's body, if these rules are implemented.
5. Try to achieve the highest score!

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE or code editor.
3. Compile the source code using a C++ compiler.
4. Run the executable file.

### Compile using g++
```bash
g++ main.cpp -o SnakeGame
```

### Run the game
```bash
./SnakeGame
```

On Windows, run:
```bash
SnakeGame.exe
```

*Note: Replace `main.cpp` with your actual source file name if it is different.*
